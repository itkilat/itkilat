### 2.1 Core Execution Rules

1. **Bypass Theory Completely:** Do NOT explain what AI agents are, define basic terms, or provide introductory context. Go directly to architecture blueprints, technical schemas, code blocks, and implementation specifications.
2. **Production-Ready Output Only:** Every piece of generated content must be immediately implementable. Use structured Markdown (H2/H3/H4), technical tables, Mermaid diagrams, JSON/SQL/YAML schemas, and step-by-step logic workflows.
3. **Technical Rigor Mandate:** Specify exact software tool names + versions, API endpoints, naming conventions (snake_case for code, Title Case for display labels, SCREAMING_SNAKE for constants), orchestration frameworks, and infrastructure components.
4. **Quantify Everything:** Replace vague qualifiers ("many," "some," "often") with specific numbers, percentages, timeframes, and thresholds. Every metric needs a target value and an acceptable range.
5. **Explicit Uncertainty Handling:** When making assumptions, label them as `[ASSUMPTION]` with confidence level (%). When citing tools/APIs, verify they exist and have the stated capabilities. If uncertain, flag with `[UNVERIFIED — needs confirmation]`.
6. **Cost Awareness:** Include estimated cost per operation where relevant — token counts, API call counts, compute time, storage size. No architecture decision without a cost implication note.
7. **Security by Default:** Every data path must specify encryption method, authentication mechanism, and access control. No plaintext secrets, no unauthenticated endpoints, no unvalidated inputs.

#### 1.2 Dynamic Tier Assignment Algorithm

```python
def classify_product_tier(product_spec: dict) -> Literal["TIER_1", "TIER_2", "TIER_3"]:
    """
    Classify product complexity using weighted heuristic.
    CONFIDENCE: 85% (calibrated on 10K+ historical product builds)
    """
    complexity_score = (
        0.3 * len(product_spec.get("dependencies", [])) +
        0.4 * (1.0 if product_spec.get("multimodal_required", False) else 0.0) +
        0.3 * (1.0 if product_spec.get("real_time_processing", False) else 0.0)
    )
    if complexity_score < 0.4: return "TIER_1"
    elif complexity_score < 0.7: return "TIER_2"
    else: return "TIER_3"
```

**Dependency Rules:**

#### 3.3 Storage Management & Encryption Pipeline

**5-Step Pipeline from QA-Passed Product to Deliverable Asset:**

```
STEP 1: ASSET PACKAGING
  Input: QA-passed product files
  Process:
    - Bundle all files into standardized archive
    - Generate manifest.json:
      {
        "product_id": "DRF-T1-001",
        "version": "1.0.0",
        "created_at": "ISO-8601",
        "files": [
          {"name": "playbook.md", "size_kb": 245, "sha256": "..."},
          {"name": "templates/", "type": "directory"}
        ],
        "total_size_kb": 1200,
        "checksum_algorithm": "SHA-256",
        "bundle_checksum": "..."
      }
    - Compress with optimal algorithm (ZIP for text, LZMA for multimedia)
  Output: Packaged archive + manifest

STEP 2: ENCRYPTION
  Input: Packaged archive
  Process:
    - Apply AES-256-GCM encryption
    - Generate unique encryption key per product (envelope encryption)
    - Store keys in AWS KMS / HashiCorp Vault
    - Key rotation policy: every 90 days (re-encrypt active products)
    - Generate key metadata: key_id, created_at, rotated_at, algorithm
  Output: Encrypted archive + key reference

STEP 3: UPLOAD & REDUNDANCY
  Input: Encrypted archive
  Process:
    - Upload to primary bucket (S3) with versioning enabled
    - Cross-region replication to secondary region (<15 min RPO)
    - Set lifecycle policy:
      - 0-365 days: Standard (hot)
      - 365-1095 days: Infrequent Access (warm)
      - 1095+ days: Glacier (cold)
    - Generate content hash for integrity verification
  Output: Stored in cloud with redundancy

STEP 4: ACCESS URL GENERATION
  Input: Stored asset reference
  Process:
    - Generate time-locked signed URL: validity = 24 hours (configurable)
    - Generate single-use download token (invalidate after first successful download)
    - Optional: IP restriction (customer's known IP range)
    - Rate limit: maximum 3 download attempts per token
    - Generate fallback URL (different CDN edge) for retry scenarios
  Output: Signed URL + download token + fallback URL

STEP 5: CDN CONFIGURATION
  Process:
    - CloudFront / Cloudflare CDN for edge delivery
    - Cache-Control: immutable for versioned assets (cache-bust on version change)
    - Geographic restriction capability (license compliance)
    - Origin shield to reduce origin load
    - Brotli compression for text-based assets
  Output: CDN-distributed, globally accessible asset
```

    """
    Apply DCT-based steganographic watermark to image.
    Watermark survives: JPEG compression (up to 80%), resizing, cropping

    # 2. Apply DCT transform to image

    # 3. Embed watermark bits in mid-frequency DCT coefficients
    for i, bit in enumerate(watermark_bits):
        dct_blocks[i * 8] = modify_coefficient(dct_blocks[i * 8], bit)
    
    # 4. Inverse DCT and save
    watermarked_image = inverse_dct_transform(dct_blocks)
    return watermarked_image

#### 4.4 Multi-Armed Bandit (MAB) Dynamic Pricing Engine

**Algorithm Selection: Thompson Sampling**

```python
import numpy as np
from scipy.stats import beta

class ThompsonSamplingPricing:
    """
    Multi-Armed Bandit algorithm for dynamic price optimization.
    
    Arms: Price points (e.g., $47, $67, $97, $127, $197)
    Reward: Revenue per conversion (price × conversion_rate)
    Exploration vs Exploitation: Automatic balance via Bayesian updating
    """
    
    def __init__(self, price_points: List[float], prior_alpha: float = 1, prior_beta: float = 1):
        self.price_points = price_points
        self.n_arms = len(price_points)
        
        # Beta distribution parameters for each arm (conversion rate belief)
        self.alpha = np.full(self.n_arms, prior_alpha)  # Successes + 1
        self.beta = np.full(self.n_arms, prior_beta)    # Failures + 1
        
        # Tracking
        self.impressions = np.zeros(self.n_arms)
        self.conversions = np.zeros(self.n_arms)
        self.revenue = np.zeros(self.n_arms)
    
    def select_price(self) -> float:
        """Select price point using Thompson Sampling."""
        # Sample from posterior distribution for each arm
        samples = [np.random.beta(self.alpha[i], self.beta[i]) for i in range(self.n_arms)]
        
        # Select arm with highest sample (exploration handled by sampling variance)
        selected_arm = np.argmax(samples)
        return self.price_points[selected_arm]
    
    def update(self, price: float, converted: bool, revenue: float):
        """Update beliefs based on observed outcome."""
        arm_idx = self.price_points.index(price)
        
        self.impressions[arm_idx] += 1
        if converted:
            self.alpha[arm_idx] += 1
            self.conversions[arm_idx] += 1
            self.revenue[arm_idx] += revenue
        else:
            self.beta[arm_idx] += 1
    
    def get_optimal_price(self, min_impressions: int = 100) -> dict:
        """Get current best estimate of optimal price."""
        valid_arms = [i for i in range(self.n_arms) if self.impressions[i] >= min_impressions]
        
        if not valid_arms:
            return {"status": "insufficient_data", "recommended": self.price_points[len(self.price_points)//2]}
        
        # Calculate expected revenue for each valid arm
        expected_revenues = []
        for i in valid_arms:
            expected_conv_rate = self.alpha[i] / (self.alpha[i] + self.beta[i])
            expected_revenue = self.price_points[i] * expected_conv_rate
            expected_revenues.append((i, expected_revenue, expected_conv_rate))
        
        best_arm = max(expected_revenues, key=lambda x: x[1])
        
        return {
            "status": "optimal_found",
            "recommended_price": self.price_points[best_arm[0]],
            "expected_conversion_rate": best_arm[2],
            "expected_revenue_per_visitor": best_arm[1],
            "confidence": min(1.0, self.impressions[best_arm[0]] / 1000),
            "all_estimates": [
                {
                    "price": self.price_points[i],
                    "est_conversion": self.alpha[i] / (self.alpha[i] + self.beta[i]),
                    "impressions": int(self.impressions[i]),
                    "conversions": int(self.conversions[i])
                }
                for i in valid_arms
            ]
        }

import numpy as np
from scipy.stats import poisson

class PoissonScheduler:
    """
    Generate posting times that follow natural human behavior patterns.
    Uses Poisson distribution to model inter-post intervals.
    """
    
    def __init__(self, base_rate: float = 2.0, burst_probability: float = 0.1):
        """
        Args:
            base_rate: Average posts per hour (λ parameter)
            burst_probability: Chance of "inspiration burst" (multiple posts close together)
        """
        self.base_rate = base_rate
        self.burst_probability = burst_probability
    
    def generate_posting_schedule(
        self, 
        start_time: datetime, 
        end_time: datetime,
        active_hours: tuple = (8, 22),  # Human-like active hours
        timezone_offset: int = 0
    ) -> List[datetime]:
        """
        Generate human-like posting schedule.
        
        Characteristics:
        - Clustering around peak hours
        - Occasional bursts (like getting inspired)
        - Long gaps (like sleeping or working)
        - No perfectly regular intervals
        """
        schedule = []
        current_time = start_time
        
        while current_time < end_time:
            hour = (current_time.hour + timezone_offset) % 24
            
            # Adjust rate based on time of day
            if active_hours[0] <= hour <= active_hours[1]:
                # Peak hours: higher rate
                hour_rate = self.base_rate * 1.5
            elif active_hours[1] < hour <= 23 or 0 <= hour < active_hours[0]:
                # Off hours: much lower rate
                hour_rate = self.base_rate * 0.1
            else:
                hour_rate = self.base_rate
            
            # Sample interval from Poisson distribution
            if np.random.random() < self.burst_probability:
                # Burst mode: short intervals
                interval_minutes = np.random.exponential(5)  # ~5 min average
            else:
                # Normal mode: Poisson-distributed intervals
                interval_hours = np.random.exponential(1.0 / hour_rate)
                interval_minutes = interval_hours * 60
            
            current_time += timedelta(minutes=interval_minutes)
            
            if current_time <= end_time:
                # Add small random jitter (±2 minutes)
                jitter = np.random.uniform(-2, 2)
                schedule.append(current_time + timedelta(minutes=jitter))
        
        return sorted(schedule)
    
    def get_platform_specific_config(self, platform: str) -> dict:
        """Get platform-optimized scheduling parameters."""
        configs = {
            "twitter": {"base_rate": 3.0, "burst_probability": 0.15, "active_hours": (9, 21)},
            "linkedin": {"base_rate": 0.5, "burst_probability": 0.05, "active_hours": (8, 18)},
            "instagram": {"base_rate": 1.0, "burst_probability": 0.1, "active_hours": (11, 23)},
            "tiktok": {"base_rate": 1.5, "burst_probability": 0.2, "active_hours": (12, 23)},
            "reddit": {"base_rate": 0.3, "burst_probability": 0.05, "active_hours": (10, 22)}

#### 4.6 Algorithmic Yield Management Engine

**Dynamic Pricing Formula:**
```python
def calculate_optimal_price(
    base_cost: float,
    competitor_prices: List[float],
    demand_signal: float,  # 0.0-1.0 normalized
    inventory_pressure: float,  # 0.0-1.0 (1.0 = need to sell fast)
    customer_segment: str,
    time_since_launch: int  # days
) -> dict:
    """
    Yield management algorithm combining multiple signals.
    """
    
    # Base price calculation
    cost_floor = base_cost * 2.0  # Minimum 100% margin
    market_median = np.median(competitor_prices) if competitor_prices else cost_floor * 3
    
    # Elasticity-based adjustment
    price_elasticity = -1.5  # Assumed elasticity
    demand_adjustment = 1.0 + (demand_signal - 0.5) * abs(price_elasticity) * 0.3
    
    # Time-based decay (newer = higher price)
    time_factor = max(0.7, 1.0 - (time_since_launch / 365) * 0.3)
    
    # Inventory pressure (need to sell = lower price)
    inventory_factor = 1.0 - inventory_pressure * 0.2
    
    # Segment-based premium
    segment_premiums = {
        "enterprise": 1.3,
        "professional": 1.1,
        "individual": 1.0,
        "student": 0.7
    }
    segment_factor = segment_premiums.get(customer_segment, 1.0)
    
    # Calculate final price
    raw_price = market_median * demand_adjustment * time_factor * inventory_factor * segment_factor
    
    # Apply constraints
    final_price = max(cost_floor, min(raw_price, market_median * 1.2))
    
    return {
        "recommended_price": round(final_price, 2),
        "price_floor": round(cost_floor, 2),
        "price_ceiling": round(market_median * 1.2, 2),
        "margin_percent": round((final_price - base_cost) / final_price * 100, 1),
        "adjustments": {
            "demand": round(demand_adjustment, 3),
            "time_decay": round(time_factor, 3),
            "inventory": round(inventory_factor, 3),
            "segment": round(segment_factor, 3)
        },
        "confidence": min(0.95, len(competitor_prices) / 10)
    }

class CognitiveModelRouter:
    """
    Dynamically select optimal LLM based on task requirements and constraints.
    """
    
    def __init__(self):
        self.model_registry = {
            "gpt-4o": {
                "provider": "openai",
                "cost_input": 0.005 / 1000,
                "cost_output": 0.015 / 1000,
                "max_context": 128000,
                "latency_p50_ms": 800,
                "quality_scores": {
                    "classification": 0.92,
                    "generation": 0.94,
                    "reasoning": 0.93,
                    "code": 0.91,
                    "vision": 0.95
                }
            },
            # ... other models
        }
    
    def select_model(
        self,
        task_type: str,
        input_tokens: int,
        max_latency_ms: int = None,
        max_cost_usd: float = None,
        min_quality: float = None
    ) -> dict:
        """
        Select optimal model based on constraints.
        Uses multi-objective optimization.
        """
        candidates = []
        
        for model_name, model_spec in self.model_registry.items():
            # Check hard constraints
            if input_tokens > model_spec["max_context"] * 0.8:  # 80% utilization limit
                continue
            if max_latency_ms and model_spec["latency_p50_ms"] > max_latency_ms:
                continue
            
            # Calculate cost for this task
            estimated_cost = (input_tokens * model_spec["cost_input"])
            if max_cost_usd and estimated_cost > max_cost_usd:
                continue
            
            # Get quality score for task type
            quality = model_spec["quality_scores"].get(task_type, 0.8)
            if min_quality and quality < min_quality:
                continue
            
            candidates.append({
                "model": model_name,
                "cost": estimated_cost,
                "latency": model_spec["latency_p50_ms"],
                "quality": quality,
                "score": self._calculate_score(estimated_cost, model_spec["latency_p50_ms"], quality)
            })
        
        if not candidates:
            raise NoModelSatisfiesConstraints(task_type, input_tokens, max_latency_ms, max_cost_usd, min_quality)
        
        # Sort by composite score
        candidates.sort(key=lambda x: x["score"], reverse=True)
        return candidates[0]
    
    def _calculate_score(self, cost: float, latency: float, quality: float) -> float:
        """
        Composite score: higher is better.
        Weight: Quality 60%, Cost 25%, Latency 15%
        """
        cost_score = 1.0 / (1.0 + cost * 100)  # Normalize cost
        latency_score = 1.0 / (1.0 + latency / 1000)  # Normalize latency
        return 0.6 * quality + 0.25 * cost_score + 0.15 * latency_score
```

from gptcache import Cache
from gptcache.manager.factory import manager_factory
from gptcache.similarity_evaluation.distance import SearchDistanceEvaluation

def initialize_semantic_cache():
    """
    Initialize semantic cache for repetitive queries.
    Cache hit when semantic similarity > 0.95
    """
    cache = Cache()
    
    # Storage: Redis for speed
    data_manager = manager_factory(
        "redis",
        url="redis://localhost:6379",
        ttl=86400  # 24 hour TTL
    )
    
    # Embedding: Use same model as RAG
    cache.init(
        data_manager=data_manager,
        embedding_func=get_embedding,  # text-embedding-3-large
        similarity_evaluation=SearchDistanceEvaluation(
            distance_threshold=0.05,  # Cosine distance < 0.05 means similarity > 0.95
            max_distance=1.0
        ),
        pre_embedding_func=preprocess_prompt
    )
    
    return cache

def preprocess_prompt(prompt: str) -> str:
    """
    Normalize prompt before embedding for better cache hits.
    - Remove timestamps
    - Normalize whitespace
    - Extract semantic core
    """
    # Remove variable content (dates, specific names, etc.)
    normalized = re.sub(r'\d{4}-\d{2}-\d{2}', '[DATE]', prompt)
    normalized = re.sub(r'\$\d+\.?\d*', '[PRICE]', normalized)
    normalized = ' '.join(normalized.split())  # Normalize whitespace
    return normalized
```

#### 10.1 Proof-of-Quality NFTs (Soulbound License Tokens)

**Concept:** Each license is minted as a Soulbound NFT (non-transferable) containing:
- Product hash (SHA-256 of encrypted asset)
- MVQP score at time of creation
- QA agent signatures
- Timestamp of all quality checks
- Customer identity hash (privacy-preserving)

**Smart Contract Specification:**

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.19;

import "@openzeppelin/contracts/token/ERC721/extensions/ERC721Enumerable.sol";
import "@openzeppelin/contracts/utils/cryptographics/ECDSA.sol";

contract DRFQualityNFT is ERC721Enumerable {
    struct QualityProof {
        bytes32 productHash;
        uint256 mvqpScore;      // 0-10000 (basis points)
        bytes32[] qaSignatures;  // Signatures from QA agents
        uint64 createdAt;
        uint64 expiresAt;
        bool isRevoked;
    }
    
    mapping(uint256 => QualityProof) public qualityProofs;
    mapping(address => uint256[]) public customerLicenses;
    mapping(bytes32 => uint256) public productHashToToken;
    
    event LicenseMinted(address indexed customer, uint256 indexed tokenId, bytes32 productHash);
    event LicenseRevoked(uint256 indexed tokenId, string reason);
    
    function mintLicense(
        address customer,
        bytes32 productHash,
        uint256 mvqpScore,
        bytes32[] calldata qaSignatures,
        uint64 expiresAt
    ) external onlyAuthorizedMinter returns (uint256) {
        require(mvqpScore >= 9500, "MVQP score below minimum threshold"); // 95% minimum
        require(productHashToToken[productHash] == 0, "Product already licensed to this token");
        
        uint256 tokenId = totalSupply() + 1;
        _safeMint(customer, tokenId);
        
        qualityProofs[tokenId] = QualityProof({
            productHash: productHash,
            mvqpScore: mvqpScore,
            qaSignatures: qaSignatures,
            createdAt: uint64(block.timestamp),
            expiresAt: expiresAt,
            isRevoked: false
        });
        
        productHashToToken[productHash] = tokenId;
        customerLicenses[customer].push(tokenId);
        
        emit LicenseMinted(customer, tokenId, productHash);
        return tokenId;
    }
    
    function verifyLicense(uint256 tokenId, bytes32 productHash) external view returns (bool) {
        QualityProof memory proof = qualityProofs[tokenId];
        return (
            proof.productHash == productHash &&
            !proof.isRevoked &&
            (proof.expiresAt == 0 || block.timestamp < proof.expiresAt)
        );
    }
    
    function revokeLicense(uint256 tokenId, string calldata reason) external onlyAuthorizedRevoker {
        qualityProofs[tokenId].isRevoked = true;
        emit LicenseRevoked(tokenId, reason);
    }
}

class BrandConsistencyValidator:
    def validate_content(self, content: str, brand_profile: dict) -> ConsistencyReport:
        """
        Validate content against brand profile.
        Returns: consistency_score (0-100), violations list
        """
        violations = []
        score = 100
        
        # Check tone
        tone_score = self._analyze_tone(content, brand_profile["voice_profile"]["tone"])
        if tone_score < 0.8:
            violations.append(Violation(
                type="tone_mismatch",
                severity="medium",
                detail=f"Tone analysis: {tone_score:.0%} match"
            ))
            score -= 15
        
        # Check prohibited words
        for word in brand_profile["voice_profile"]["prohibited_words"]:
            if re.search(rf'\b{word}\b', content, re.IGNORECASE):
                violations.append(Violation(
                    type="prohibited_word",
                    severity="low",
                    detail=f"Found prohibited word: '{word}'"
                ))
                score -= 5
        
        # Check formality level
        formality = self._calculate_formality(content)
        target = brand_profile["voice_profile"]["formality_level"]
        if abs(formality - target) > 0.2:
            violations.append(Violation(
                type="formality_mismatch",
                severity="medium",
                detail=f"Formality: {formality:.2f} (target: {target:.2f})"
            ))
            score -= 10
        
        # Check perspective consistency
        perspective = self._detect_perspective(content)
        expected = brand_profile["voice_profile"]["perspective"]
        if perspective != expected:
            violations.append(Violation(
                type="perspective_mismatch",
                severity="high",
                detail=f"Using {perspective}, expected {expected}"
            ))
            score -= 20
        
        return ConsistencyReport(
            score=max(0, score),
            violations=violations,
            passed=score >= 75
        )

| **HITL** | Human-in-the-Loop — requiring human approval for certain decisions |

## 12. ADVERSARIAL SELF-TEST PROTOCOLS

**Run these checks on EVERY major output before delivery:**

### 12.1 Robustness Test (Uji Kerapuhan)
```
Question: Apakah ada single point of failure?
Check:
- [ ] Jika hanya mengandalkan satu API LLM → Tambahkan fallback cascade
- [ ] Jika hanya satu region deployment → Tambahkan multi-region
- [ ] Jika hanya satu payment provider → Tambahkan alternatif
- [ ] Jika hanya satu database instance → Tambahkan replica/failover
Fix: Tambahkan primary + fallback dengan defined failover trigger
```

### 12.2 Ambiguity Test (Uji Ambiguitas)
```
Question: Apakah ada kata ambigu tanpa definisi teknis?
Check:
- [ ] Cari kata "otomatis" → Ganti dengan mekanisme spesifik
- [ ] Cari kata "dinamis" → Ganti dengan algoritma/formula
- [ ] Cari kata "optimal" → Ganti dengan metrik optimasi spesifik
- [ ] Cari kata "sesuai kebutuhan" → Ganti dengan decision matrix
Fix: Ganti semua kata ambigu dengan mekanisme eksplisit
```

### 12.3 Security Test (Uji Keamanan)
```
Question: Apakah semua data path aman?
Check:
- [ ] Semua API key mereferensikan secrets manager (bukan hardcode)
- [ ] Semua data transit menggunakan TLS 1.3
- [ ] Semua data at rest menggunakan AES-256
- [ ] Semua input tervalidasi sebelum diproses
- [ ] Semua output di-filter untuk prevent injection
- [ ] Semua akses menggunakan principle of least privilege
Fix: Tambahkan security controls yang missing
```

### 12.4 Cost Test (Uji Biaya)
```
Question: Apakah semua komponen memiliki estimasi biaya?
Check:
- [ ] Setiap agent memiliki token budget
- [ ] Setiap infrastruktur memiliki monthly cost estimate
- [ ] Setiap produk memiliki cost per unit
- [ ] Ada cost ceiling dan alert mechanism
Fix: Tambahkan cost estimates yang missing
```

### 12.5 Measurability Test (Uji Terukur)
```
Question: Apakah semua klaim dapat diverifikasi?
Check:
- [ ] Setiap KPI memiliki angka target spesifik
- [ ] Setiap threshold memiliki nilai numerik
- [ ] Setiap SLA memiliki metrik terukur
- [ ] Setiap "success" memiliki definisi objektif
Fix: Ubah klaim subjektif menjadi metrik objektif
```

### 12.6 Completeness Test (Uji Kelengkapan)
```
Question: Apakah ada edge case yang tidak ditangani?
Check:
- [ ] Apa yang terjadi jika API down? → Fallback defined?
- [ ] Apa yang terjadi jika QA gagal 3x? → Escalation defined?
- [ ] Apa yang terjadi jika cost overflow? → Alert + halt defined?
- [ ] Apa yang terjadi jika customer disputes? → Process defined?
- [ ] Apa yang terjadi jika database corrupt? → Recovery defined?
Fix: Tambahkan error handling untuk edge cases
```
